# EcoPlay Web

Landing page and backend for Eco-Play, a gamified sustainability/recycling TCC (capstone) project.

## Tech stack
- Backend: Fastify 5, Prisma 6, @fastify/jwt, mqtt, zod, helmet
- Web: Next.js 15 (App Router/Turbopack), React 19, Tailwind CSS 4, Radix UI, TanStack Query, React Hook Form, Axios, Framer Motion

## Running
Each part has its own `package.json` — see `backend/` and `web/` for setup and run instructions.
